### OpenCV: Open Source Computer Vision Library

#### Resources

* Homepage: <http://opencv.org>
* Docs: <http://docs.opencv.org/master/>
* Q&A forum: <http://answers.opencv.org>
* Issue tracking: <https://github.com/opencv/opencv/issues>

#### Contributing

Please read before starting work on a pull request: <https://github.com/opencv/opencv/wiki/How_to_contribute>

Summary of guidelines:

* One pull request per issue;
* Choose the right base branch;
* Include tests and documentation;
* Clean up "oops" commits before submitting;
* Follow the coding style guide.

## English project overview

A personal fork of the OpenCV computer vision library from opencv/opencv, containing vision modules, samples and CMake build configuration for source exploration, learning and upstream development.

**Getting started:** Start with the official documentation and contribution guide linked in the original README. See CMakeLists.txt for source configuration and samples/ for examples.

**Scope:** This fork does not represent the latest upstream release; credit remains with the original authors and contributors.
